This page collects educational resources — not a complete curriculum. Start with what your project needs; ask lab members what they actually use day to day.

## Electrophysiology & neural signal processing

- [MNE-Python](https://mne.tools/) — EEG/MEG/iEEG analysis in Python
- [FieldTrip](https://www.fieldtriptoolbox.org/) — MATLAB toolbox for electrophysiology
- Spectral / oscillatory methods: [FOOOF](https://fooof-tools.github.io/fooof/), [ByCycle](https://bycycle-tools.github.io/bycycle/)
- [Tom Donoghue's Electrophysiology & Open Science Resources](https://tomdonoghue.github.io/resources) — curated lists of electrophysiology software, open datasets, single-unit tools, DSP visualizers, and project templates

## Technical guides for skill learning

### Introductions to coding

1. [Programming with Python (Software Carpentry)](https://swcarpentry.github.io/python-novice-inflammation/) — hands-on introduction to Python built around scientific data analysis
2. [Plotting and Programming in Python (Software Carpentry)](https://swcarpentry.github.io/python-novice-gapminder/) — introductory Python 3 programming and data visualization with the Gapminder dataset
3. [Python for the Practicing Neuroscientist (Case Studies in Neural Data Analysis)](https://mark-kramer.github.io/Case-Studies-Python/01.html) — Mark Kramer & Uri Eden's interactive Python on-ramp using neural recordings

### Introduction to Jupyter

1. [Teaching and Learning with Jupyter](https://github.com/jupyter4edu/jupyter-edu-book) — handbook and repository on using Jupyter notebooks effectively for computation and exploration

### Introduction to statistics (not Python)

1. [Statistical Thinking for the 21st Century](https://statsthinking21.github.io/statsthinking21-core-site/) — Russell Poldrack's modern textbook on statistical modeling, resampling, and reproducible inference

### More advanced (bringing all of the above together)

1. [Neural Data Science in Python](https://neuraldatascience.io/intro.html) — Aaron Newman's comprehensive textbook integrating Python, data science workflows, and neuroscience data (single-unit, EEG, and fMRI)

## Scientific Python, Git & reproducible workflows

- [The Good Research Code Handbook](https://goodresearch.dev/index.html) — practical software engineering and project organization for research code
- [Experimentology](https://experimentology.io/) — open science approaches to experimental psychology methods, study design, and reproducible reporting
- [GitHub Skills / Git guides](https://skills.github.com/) — version control basics
- Virtual environments (`conda` / `venv`) and dependency pinning for analysis repos
- Data standards: [Neurodata Without Borders (NWB)](https://www.nwb.org/), [BIDS](https://bids.neuroimaging.io/)

## Computational modeling & statistics

- [Neuromatch Academy](https://neuromatch.io/) — computational neuroscience and ML courses

## High-performance computing at Rutgers

- [Rutgers Amarel](https://oarc.rutgers.edu/resources/amarel/) — cluster overview and getting an account
- Linux / SSH basics for remote work
- Slurm job scripts: start from OARC examples and lab templates
